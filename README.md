# 🗺️ Belém Tour – COP30

O **Belém Tour – COP30** é uma aplicação web desenvolvida para facilitar a exploração de pontos turísticos, gastronomia e passeios na cidade de Belém do Pará, servindo como um guia prático para os visitantes e participantes da COP30. A plataforma organiza as experiências da cidade em categorias intuitivas e permite o gerenciamento de agendamentos.

---

## 🚀 Funcionalidades

- **Categorização de Passeios:** Separação de rotas em City Tour, Passeios Ecológicos, Turismo Gastronômico e Passeios Fluviais.
- **Interface Responsiva:** Design limpo e adaptável para navegação em diferentes tamanhos de tela.
- **Sistema de Agendamentos:** Integração com backend para visualizar e gerenciar os agendamentos dos usuários.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

- **Python**: Linguagem base para a lógica do servidor.
- **Django**: Framework web para o desenvolvimento do backend, rotas e gerenciamento de banco de dados.
- **HTML5 / CSS3**: Estruturação e estilização da interface do usuário (Front-end).

---

## 📁 Estrutura do Projeto (Destaques)

- `views.py`: Lógica de renderização das páginas e processamento dos agendamentos.
- 
- `models.py`: Estruturação do banco de dados para os passeios e agendamentos.
- 
- `templates/`: Arquivos HTML responsáveis pela interface visual apresentada ao usuário.
