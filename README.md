# Belém Tour – COP30

Aplicação web desenvolvida com Django para apresentar pontos turísticos,
gastronomia e passeios em Belém do Pará.

O sistema organiza experiências turísticas por categorias e possui
funcionalidades relacionadas a agendamentos.

## Tecnologias

- Python
- Django
- HTML5
- CSS3
- SQLite

## Funcionalidades

- Categorias de passeios
- City Tour
- Passeios ecológicos
- Turismo gastronômico
- Passeios fluviais
- Sistema de agendamentos
- Interface responsiva
